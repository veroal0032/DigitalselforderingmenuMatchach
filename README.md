# Matcha Chá — Kiosko de autoservicio digital

Sistema de pedidos para un café de matcha, diseñado y desarrollado de forma integral: desde la experiencia de usuario hasta la implementación con base de datos y analytics en tiempo real.

El proyecto nació como una exploración de diseño de interiores para un café de matcha y evolucionó en un kiosko funcional completo — el proceso creativo forma parte del concepto.

## Funcionalidades

- Navegación por categorías y selección de productos
- Carrito de compras con gestión de pedido
- Autenticación de usuarios vía Supabase
- Analytics de comportamiento con PostHog
- Notificaciones por email con Resend
- UI responsive adaptada a pantallas kiosko

## Correr localmente

```bash
npm install
npm run dev
```

## Contexto de diseño

El diseño partió de un brief de arquitectura de interiores para un café de matcha. La identidad visual, la selección tipográfica y la paleta de color surgieron de ese proceso — no al revés.
